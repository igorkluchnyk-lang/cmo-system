# CMO — оркестратор маркетингу для Claude Code

Система, у якій Claude виступає директором з маркетингу: веде продукт від сирої ідеї до запущеної
кампанії через **8 фаз**, підключаючи **12 спеціалізованих агентів** і **21 файл бази знань**,
і **не пускає проєкт далі, поки не сходиться юніт-економіка**.

```
                        /cmo
                          │
        ┌─────────────────┴─────────────────┐
        │        ОРКЕСТРАТОР (SKILL.md)     │
        │  12 законів · 8 фаз · гейт · DoD  │
        └─────────────────┬─────────────────┘
                          │
   ┌──────────┬───────────┼───────────┬──────────┐
   ▼          ▼           ▼           ▼          ▼
 Ф1 ринок  Ф2 гіпотези  Ф3 ГЕЙТ   Ф4 смисли  Ф5-7 запуск
 market    research     economics  positioning funnel
 competitors            pricing    brand       launch
                          │                    analytics
                     ┌────┴────┐
                     │ 🔴 СТОП │  contribution ≤ 0
                     │ 🟡 ПАУЗА│  LTV/CAC < 3
                     │ 🟢 ГОУ  │
                     └─────────┘
```

## Головна ідея

Більшість «AI-маркетологів» генерують текст. Цей — **зупиняє тебе**, коли цифри не сходяться.

Після Фази 3 стоїть жорсткий гейт:
- `contribution ≤ 0` → **СТОП**, ріст працює проти бізнесу
- `LTV/CAC < 3` або payback за горизонтом → **не масштабуємо**, шукаємо важелі
- стрес-тест ламає модель → запускати обережно й малим бюджетом

Рішення «не запускати» ухвалюється **тільки після чесного проходу по всіх важелях**:
`ціна → пакетування → сегмент → канал → гео → лінійка → продажі → виконання`

## Встановлення

```bash
git clone https://github.com/igorkluchnyk-lang/cmo-system.git
cd cmo-system

# агенти
mkdir -p ~/.claude/agents && cp agents/*.md ~/.claude/agents/

# оркестратор і база знань
mkdir -p ~/.claude/skills && cp -r skills/cmo ~/.claude/skills/

# свій контекст бізнесу (необов'язково, але сильно покращує результат)
cp ~/.claude/skills/cmo/references/business-context.template.md \
   ~/.claude/skills/cmo/references/business-context.md
```

Далі відкрий Claude Code і напиши `/cmo`. Працює в будь-якому чаті на цій машині.

## Як викликати

| Запит | Що станеться |
|---|---|
| `/cmo` + опис продукту | Повний цикл: бриф → 8 фаз → GTM-план |
| «Порахуй, чи вигідно» | Одразу Фаза 3 — економіка й ціна |
| «Кому це продавати» | Фази 1–2: ринок, конкуренти, ICP, гіпотези |
| «Чому не продається» | Діагностика: симптом → чи модель жива → сходи ескалації |
| «Покращ сторінку / текст» | Позиціювання + воронка паралельно |
| «Хочу працювати з блогерами» | Агент креаторського каналу зі своїм гейтом |
| «Виходимо в іншу країну» | CAGE, стоп-фактори, Gate 30/60/90 |

Скіл також підхоплюється сам на фразах «запускаємо продукт», «план запуску», «go-to-market»,
«стратегія на квартал», «зроби кампанію».

## Що всередині

**12 агентів** — ринок · конкуренти · дослідження · економіка (гейт) · ціна · позиціювання ·
бренд-система · воронка · креаторський канал · запуск · експансія · аналітика

**21 файл бази знань** — юніт-економіка, CAC, декомпозиція, точка А, когорти, ICP/JTBD,
CustDev і The Mom Test, PMF, CJM, оффер за Хормозі й упаковка, GTM, гіпотези й HADI,
вимірювання й атрибуція, міжнародна експансія, креаторська фабрика

**12 наскрізних законів**, які застосовуються автоматично в кожній фазі — від
«клієнт для всіх = клієнт ніхто» до «гіпотеза не стартує без готового трекінгу»

**Definition of Done на кожній фазі** і **чек-лист на 17 пунктів** перед фінальним результатом

## Джерела

База знань зібрана як **власні конспекти** з відкритих матеріалів:

- **«Маркетологія»** — безкоштовний курс із системного маркетингу Андрія Чумаченка
  (Netpeak / BASE) та Артема Бородатюка (FRACTAL). Опубліковано 5 модулів із 8.
  Тут — переказ і структурування ключових ідей, не копія матеріалів курсу.
- **$100M Offers, Алекс Хормозі** — ціннісне рівняння, MAGIC, Grand Slam Offer
- **AI-КОВЧЕГ 2.0**, воркшоп «Маркетинг та упаковка» — ланцюг 1-1-1 → ДНК клієнта → оффер → лендінг

Оригінальні курси й книга — у їхніх авторів. Якщо матеріал корисний — пройди першоджерела.

## Чого тут немає

Курс «Маркетологія» опубліковано на 5 модулів із 8 — **інструментальні модулі**
(Brand, Leadgen, Retention) і «Керування командою» **автором ще не написані**.
Систему це не ламає: оркестратор уміє підключати окремі скіли під конкретні інструменти
(реклама, SEO, email, CRO, контент), якщо вони встановлені на машині.
